## 💡 Что это

**FLIDE** — проект по кастомизации iOS-приложений. Берём расшифрованный `.ipa`, пишем твик, встраиваем его в приложение и собираем готовый `.ipa` прямо в GitHub Actions.

> **Это не читы.** Мы не ломаем онлайн-механики, не трогаем чужие аккаунты и не даём преимуществ над другими игроками.
> Мы делаем приложения **удобнее и чище** для себя.

## ✅ Что делаем / ❌ Чего не делаем

| ✅ Делаем | ❌ Не делаем |
|---|---|
| Убираем навязчивую и 18+ рекламу | Читы и преимущества в онлайне |
| Кастомные темы, иконки, интерфейс | Взлом чужих аккаунтов и данных |
| Скрываем лишние баннеры и попапы | Обход платежей и продажа «модов» |
| Настройки, которых не хватает в оригинале | Вредоносный код, трекеры, майнеры |

## ⚙️ Как это работает

```
 расшифрованный .ipa ──►  твик (Theos / Logos)  ──►  GitHub Actions  ──►  готовый .ipa
        📦                     🛠️                       ☁️                    📲
```

1. **Приложение** — кладём расшифрованный `.ipa` (ссылкой или в релиз).
2. **Твик** — пишем хуки на Objective-C в папке `tweaks/<название>/`.
3. **Сборка** — GitHub Actions собирает `.dylib` и встраивает его в `.ipa`.
4. **Установка** — скачиваем артефакт и ставим через **Sideloadly / AltStore / TrollStore** или подписываем своим сертификатом.

Никакого Mac, никакого Xcode — всё в облаке.

### ✨ HD-пак
1. FLIDE → 📦 → «Экспортировать все текстуры в zip» → сохрани в «Файлы».
2. Загрузи zip в **Releases** с тегом `hd-src`.
3. **Actions → HD texture pack → Run workflow** → скачай `FLIDE-HD-pack`.
4. Распакуй в «Файлах» → FLIDE → 📦 → «Импорт пака» → включи.

## 🚀 Как собрать

1. Загрузи расшифрованный `.ipa` в **Releases** (тег, например, `IPA`).
2. **Actions → Build tweaked IPA → Run workflow**, укажи папку твика, тег и маску файла.
3. Через пару минут скачай артефакт `FLIDE-<app>-ipa` и поставь через **Sideloadly / AltStore**.

## 📜 Принципы

- **Честность** — открытый код, видно каждую строчку твика.
- **Уважение** — только личное использование, без распространения чужого платного контента.
- **Чистота** — никакой рекламы, телеметрии и сюрпризов внутри наших сборок.
